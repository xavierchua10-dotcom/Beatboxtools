# Audio-Tools

Savior's beatbox practice tools in one app, with a bottom tab bar.

- **Metronome** (`metronome.html`): BPM, accent, subdivisions, tap tempo
- **Battle** (`battle.html`): battle round timer with 60/120/150/200 sec rounds and a Voice, Horn or Ringing buzzer

`index.html` is the shell that holds both. Each tool keeps running when you switch tabs, so the metronome can keep clicking while you check the round timer.

Open a tab directly with `#metronome` or `#battle` on the end of the link.

Merged from the former `savior-audio` and `Saviortimer` repos. The two tool files are unchanged copies of the originals.
